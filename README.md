# Drug Repurposing Pipeline for Alzheimer's

- **The Problem:** Developing a brand-new brain drug takes over a decade and billions of dollars, so pharma companies love repurposing existing approved drugs for neurodegenerative diseases (like Alzheimer's or Parkinson's).
- **The Pipeline:** Take public gene-expression data from diseased brain tissue (for example, from GEO/ADNI) and compare it against drug-perturbation databases (for example, LINCS L1000). Build a clean workflow that scores which FDA-approved compounds reverse the disease's molecular signature and maps them to protein-protein interaction networks.
